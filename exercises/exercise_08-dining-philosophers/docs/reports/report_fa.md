# گزارش فارسی — تمرین 8: فیلسوفان غذاخور: بن‌بست و گرسنگی زیر سیاست Lottery

## چکیده

استفاده از بلیت برای انتخاب فیلسوفِ مجاز، جلوگیری از بن‌بست و تحلیل محدودیت گرسنگی. این گزارش منطق الگوریتم، فرض‌های مدل و شواهد حاصل از اجرای کد را از ادعاهای عمومی جدا می‌کند.

## مسئله و هدف

این تمرین از Lottery برای انتخاب میان فیلسوفانی استفاده می‌کند که در لحظهٔ تصمیم هر دو چنگال مجاورشان آزاد است. برای جلوگیری از بن‌بست، حداکثر N−1 فیلسوف اجازهٔ ورود به اتاق دارند و جفت چنگال‌های هر فیلسوف به‌صورت اتمی رزرو می‌شود؛ بنابراین حالت hold-and-wait در مدل رخ نمی‌دهد.

به هر فیلسوف وزن بلیت پایه اختصاص داده می‌شود. اگر aging فعال باشد، با افزایش زمان انتظار وزن مؤثر افزایش پیدا می‌کند تا احتمال انتخاب فیلسوفی که مدت بیشتری منتظر مانده بیشتر شود. در شبیه‌سازی ۵ فیلسوف، هر کدام سه وعده می‌خورند و trace شروع/پایان هر وعده ذخیره می‌شود. هیچ دو فیلسوف مجاور نباید هم‌زمان مشغول غذا خوردن باشند.

مهم: Lottery حتی با aging تضمین قطعی bounded waiting ایجاد نمی‌کند؛ احتمال یک دنبالهٔ طولانی باخت صفر نیست. نتیجهٔ اجرای محدود فقط نشان می‌دهد در آن seed خاص همهٔ وعده‌ها کامل شده‌اند. برای تضمین قطعی گرسنگی‌ناپذیری باید FIFO یا رزرو نوبت قطعی به کار رود.

## مدل و روش اجرا

سناریوی این تمرین در `shared/experiments.py` تعریف شده و با تابع `run_exercise(8)` اجرا می‌شود. منبع دادهٔ گزارش، فایل `outputs/results.json` است. برای تکرار نتیجه، نسخهٔ کد و seed ثبت‌شده باید ثابت باشد.

## شبه‌کد Lottery

```text
while unfinished jobs exist:
    ready = jobs with arrival <= now and remaining > 0
    if ready is empty:
        advance time to next arrival
        continue
    T = sum(ticket[p] for p in ready)
    r = uniform_integer(1, T)
    winner = first job whose cumulative ticket interval contains r
    run winner for min(quantum, remaining[winner])
    update remaining time, first response and completion
```

## معیارهای ارزیابی

صحت ورودی‌ها، یکتایی شناسه‌ها، مثبت‌بودن ticket و burst، تکمیل همهٔ عملیات، سازگاری شمارنده‌ها، تکرارپذیری seed و صحت metricها بررسی می‌شود. زمان انتظار، پاسخ و turnaround از trace استخراج می‌شوند، نه از عددگذاری دستی.
