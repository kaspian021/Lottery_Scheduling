# گزارش فارسی — تمرین 5: نمایش اجرای Lottery با Semaphore و Monitor

## چکیده

ساخت trace و تصویر مرحله‌ای از انتخاب بلیت و حفاظت هم‌زمانی با Semaphore/Monitor. این گزارش منطق الگوریتم، فرض‌های مدل و شواهد حاصل از اجرای کد را از ادعاهای عمومی جدا می‌کند.

## مسئله و هدف

این تمرین یک نمایش مرحله‌ای از زمان‌بند Lottery ارائه می‌کند و نقش همگام‌سازی را در حفاظت از انتخاب برنده نشان می‌دهد. دو نسخهٔ دمو با Semaphore و Condition اجرا می‌شوند. هر نخ برای انجام قرعه به بخش بحرانی وارد می‌شود، عدد بلیت را می‌گیرد، بازهٔ تجمعی را پیمایش می‌کند و شمارندهٔ برنده را به‌روزرسانی می‌کند.

خروجی اصلی شامل تعداد قرعه‌ها، شمارندهٔ برد هر گروه و trace انتخاب‌هاست. از آن trace نمودار/انیمیشن ساخته می‌شود؛ چون ترتیب اجرای نخ‌ها به زمان‌بند سیستم‌عامل وابسته است، trace رقابتی ممکن است بین اجراها تغییر کند. معیار قابل اتکا در این دمو، تعداد عملیات کامل و invariant شمارنده‌هاست، نه ادعای benchmark قطعی.

Semaphore ظرفیت ورود به بخش بحرانی را کنترل می‌کند؛ Condition/Monitor امکان انتظار و اعلان تغییر وضعیت را می‌دهد. این دو ابزار را باید با سیاست انتخاب Lottery جدا دانست: Lottery می‌گوید چه کسی انتخاب شود، primitive همگام‌سازی تضمین می‌کند تغییر وضعیت مشترک خراب نشود.

## مدل و روش اجرا

سناریوی این تمرین در `shared/experiments.py` تعریف شده و با تابع `run_exercise(5)` اجرا می‌شود. منبع دادهٔ گزارش، فایل `outputs/results.json` است. برای تکرار نتیجه، نسخهٔ کد و seed ثبت‌شده باید ثابت باشد.

## شبه‌کد Lottery

```text
while unfinished jobs exist:
    ready = jobs with arrival <= now and remaining > 0
    if ready is empty:
        advance time to next arrival
        continue
    T = sum(ticket[p] for p in ready)
    r = uniform_integer(1, T)
    winner = first job whose cumulative ticket interval contains r
    run winner for min(quantum, remaining[winner])
    update remaining time, first response and completion
```

## معیارهای ارزیابی

صحت ورودی‌ها، یکتایی شناسه‌ها، مثبت‌بودن ticket و burst، تکمیل همهٔ عملیات، سازگاری شمارنده‌ها، تکرارپذیری seed و صحت metricها بررسی می‌شود. زمان انتظار، پاسخ و turnaround از trace استخراج می‌شوند، نه از عددگذاری دستی.
